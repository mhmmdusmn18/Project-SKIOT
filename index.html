Deskripsi

Sistem ini mensimulasikan rumah pintar berskala miniatur dengan tiga ruangan: Ruang Tamu, Kamar, dan Garasi. Satu sensor PIR memantau area umum untuk keamanan, sementara tiga lampu dapat dikendalikan secara terpisah dari jarak jauh melalui dashboard web. Status dikirim secara real-time menggunakan ESP8266 dan protokol MQTT.

Fitur Utama

  • ● Deteksi gerakan area umum (1 sensor PIR)
  • ● Kendali lampu jarak jauh, per ruangan
  • ● Mode keamanan, aktif / nonaktif
  • ● Histori deteksi gerakan
